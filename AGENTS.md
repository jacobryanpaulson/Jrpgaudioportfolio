# AGENTS.md

## Project Context

This is a standalone React portfolio built with Vite. Treat it as user-owned
application code, keep changes focused on the user's request, and preserve
existing project conventions.

Start with `README.md` for local setup, content editing, and deployment.

## Key Files

- `src/`: frontend application source.
- `src/data/sampleContent.js`: editable portfolio profile, media, and mixer data.
- `public/`: static files copied directly to the production build.
- `vite.config.js`: Vite and React configuration.

## Working Notes

- Use `npm run dev` for local development.
- Run the relevant checks from `package.json` before finishing code changes.
